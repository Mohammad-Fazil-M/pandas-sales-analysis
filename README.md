# Pandas Sales Analysis

## Project Overview

This project analyzes a small retail sales dataset using Python, Pandas, and NumPy.

The goal is to practice data cleaning, missing-value analysis, revenue calculation, aggregation, data quality checks, and reporting.

## Objectives

- Inspect and understand the dataset
- Standardize product and city names
- Convert date strings into datetime values
- Calculate revenue from quantity and unit price
- Analyze sales by product
- Identify missing values and potential duplicate records
- Validate calculations and document data quality limitations

## Tools

- Python
- Pandas
- NumPy
- Git and GitHub

## Data Quality Considerations

- Missing values are not automatically replaced with zero.
- Potential duplicate records are investigated before any deletion.
- Revenue totals represent recorded, calculable revenue and may not equal actual total revenue when data is incomplete.
- The original dataset is preserved separately from the working copy.

## Project Status

In progress — data preparation, validation, and reporting are being developed step by step.

## How to Run

Install the dependencies:

```bash
pip install -r requirements.txt
```

Then run:

```bash
python sales_analysis.py
```
